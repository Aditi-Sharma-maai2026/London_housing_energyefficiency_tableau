# Data

This folder contains the dataset used in the **Navigating Inequality: How Economic Disparities Affect London's Housing Landscape** project.

The data brings together property transaction records and housing energy performance indicators to explore patterns in London's housing market.

### Key Variables

- Property prices and transaction dates
- Postcodes and London geographical classifications
- Property type, tenure and new-build status
- Floor area and number of rooms
- Energy efficiency ratings and EPC indicators

### Data Preparation

The dataset was explored and used to support the Tableau visualisations examining housing affordability, property ownership and energy efficiency across London.

**Note:** Some variables contain missing values. These should be considered when interpreting the analysis and visualisations.

### Data Source

The dataset is based on London property and energy performance records. Please refer to the original dataset documentation for source details and usage permissions.
